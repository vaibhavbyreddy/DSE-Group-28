\section{Control Forces}
\label{sec:control_forces}
The forces and moments on the control surfaces were calculated using the Flow5 software. This software uses a potential flow solver, viscosity and wake models for preliminary estimation of aircraft characteristics. These include lift distribution, drag estimation, static stability and dynamic stability analysis. \footnote{\href{https://flow5.tech/docs/flow5_doc/flow5_doc.html}{Flow5 methods overview}(Accessed on 08.06.2026)} The aircraft was modeled and meshed in this software using the fuselage CAD model and a built-in wing generation tool, which was used for the main wing, tail and canard surfaces. Control surface size was estimated based on the reference aircraft. The output from Flow5 gives a range of moment values for the actuators needed for the control surface deflections. Furthermore, the Flow5 aircraft model is used together with its inertial properties coming from the CAD model to estimate dynamic stability characteristics of HUGO.

This size is smaller than other reference aircraft, which is caused by the range of velocities the aircraft operated in. The horizontal empennage of the DAST drone did not feature an elevator. \subsection{Ailerons}
Based on this information, the roll characteristics were initially tested using the original wing planform \todo{reference this} with ailerons having a 20 \% chord-to-length ratio, spanning 25 \% of the half-wing span and located at the wing center. These control surfaces were tested in an approximate approach speed regime, where $V_{appr} = 50 \ m \cdot s^{-1}$ at an angle of attack $\alpha=6.5 \degree$. The air used in the analysis had a zero-altitude ISA density, i.e. $\rho = 1.225 \ kg \cdot m^-3$. Each aileron has been set to 20 \degree deflection. At this flight velocity, the maximum calculated hinge moment on a single aileron is $0.0408 \ N\cdot m$, with both ailerons deflected in opposite directions. The resulting roll rate p is calculated using \autoref{eq:roll_rate} for steady-state roll rate \cite{nelson1998flight}.
\begin{equation}
    p = -2 \frac{V}{b} \frac{C_{l_{\delta_{a}}}}{C_{l_{p}}}\delta_a
    \label{eq:roll_rate}
\end{equation}
Here, $V = V_{appr}$, $b = 2.66m$ is the wing span, $C_{l_{\delta_{a}}}$ is the control derivative representing the change of $C_l$ with aileron deflection $\delta_a$ and $C_{l_{p}} = -0.76344$ is the stability derivative of the change of $C_l$ with the roll rate $p$ found using Flow5. The only unknown parameter is the change of the roll moment coefficient with aileron deflection $C_{l_{\delta_{a}}}$. This parameter was calculated at the approach speed $V_{appr} = 50 \ m \cdot s^{-1}$ from the change of $C_l$ between two aileron deflections $\delta_a = 0 \degree$ and $\delta_a = \pm0.1 \degree$. This resulted in $C_{l_{\delta_{a}}} = -0.19 \ rad^{-1}$. The roll rate $p$ at different aileron deflections $\delta_{a}$ are shown in \autoref{tab:delta_a_alpha}.

Note that \autoref{eq:roll_rate} uses small-angle approximation, therefore values tend towards less accuracy as $\delta_a$ increases. \\

At the target experiment flight speed at $M = 0.75$, the required aileron deflection to reach the approach roll rate has been found to be $\delta_a = \pm3.92 \degree$. Flow5 outputs a moment $H_a = 0.179 \ N \cdot m$ for a single aileron at this speed regime. This speed lies in compressibility region, therefore accounting for this in the hinge moment is needed. Using the expression in \autoref{eq:hinge_moment} \cite{}, value obtained in Flow5 was then scaled using the Prandtl-Glauert compressibility correction in \autoref{eq:ch_compressibility}, analogous to the method Simpson used \cite{Simpson2016}.

\begin{equation}
    \label{eq:hinge_moment}
    C_h =\frac{H_a}{qS_ac_a} \approx 0.0345
\end{equation}
\begin{equation}
    \label{eq:ch_compressibility}
    C_{h_{c}} = \frac{C_h}{\sqrt{1-M^2}} = \frac{0.0345}{\sqrt{1-0.75^2}} \approx0.0522
\end{equation}
From this, the updated aileron hinge moment $H_{a_{c}} \approx 0.27\  N \cdot m$ was obtained. This value is important for the aileron actuator selection.
